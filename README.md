# UK online retail, 2009-2011: sales, retention and customer value in SQL

SQL analysis of the UCI Online Retail II data set: two years of orders from a
UK online gift retailer, about a million lines. Work in progress.

Data: Chen, D. (2019). Online Retail II [Dataset]. UCI Machine Learning
Repository. https://doi.org/10.24432/C5CG6D (CC BY 4.0). The data is not
redistributed here.
