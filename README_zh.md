# 英国在线零售 2009–2011：用 SQL 做销售、留存与客户价值分析

（英文完整版见 [README.md](README.md)，本文是摘要。）

对 UCI 公开数据集 Online Retail II（一家英国礼品在线零售商两年、约 107 万行真实交易）做的 SQL 分析：数据体检与清洗、建星型模型（多表关联）、月度趋势、同期群留存、RFM 分层、复购、退货、国家与商品分析。结果表导出为 CSV，用于 Tableau Public 仪表板和 README 里的图。

## 关键数字（清洗后）

| | |
|---|---|
| 时间范围 | 2009-12-01 至 2011-12-09 |
| 销售发票 / 取消单 | 39,516 / 7,405 |
| 有购买记录的注册客户 | 5,852（另有无客户号的散客，占销售额 13%） |
| 商品数 | 4,908 |
| 净收入（销售减取消） | £18.9M |
| 同口径年度对比 | 净收入 +1.9%，订单数 −4.0%，客单价 +6.8% |

## 用什么做的

* **SQL（DuckDB）**：所有分析。DuckDB 是单文件分析型数据库，不用装服务器，语法接近 PostgreSQL；除了几个 DuckDB 自带的函数，SQL 都是标准写法，换到 PostgreSQL 或 MySQL 只需少量修改。
* **Python**：只用于 Excel 转 CSV、按顺序执行 SQL 文件、画 README 里的图。
* **Tableau Public**：[仪表板](https://public.tableau.com/app/profile/shihaozhou/viz/online_retail_dashboard_17905439682910/OnlineRetailII)，数据来自导出的 CSV（哪个文件对应哪张图见 `docs/dashboard.md`）。

## 怎么跑

```bash
pip install -r requirements.txt
python scripts/00_download_data.py     # 从 UCI 下载 45 MB 原始数据
python scripts/01_excel_to_csv.py      # 两个 Excel 表页合成一个 CSV，约 2 分钟
python scripts/run_sql.py sql          # 按 00 → 99 顺序跑完所有 SQL，打印每一步结果
python scripts/make_charts.py          # 生成 README 用的四张图
python scripts/sql_shell.py            # 可选：打开一个提示符自己敲查询
```

## 数据清洗要点（`sql/01`、`sql/02`）

* 两个 Excel 表页在 2010-12-01 至 12-09 完全重复（22,523 行），直接合并会重复计数——去掉第二张表页的这段。
* 同一表页内还有 12,133 行完全重复的明细行，保留一条。
* 发票号以 `C` 开头的是取消单（负数量），保留并打标记；全项目的收入口径都是"净收入 = 销售 − 取消"。
* 邮费、手工调整、银行手续费、亚马逊费用、样品、坏账、测试行、礼品券等非商品行剔除；单价 ≤ 0 的行（免费品、库存报损）剔除。
* 22.8% 的行没有客户号（散客）：算收入时保留，算客户类指标时排除。
* 同一商品多个描述、同一客户多个国家：维表取出现最多的那个。

## 主要结论

1. **趋势**：两个完整年度净收入 £9.16M → £9.33M（+1.9%），订单少了 4%、客单价涨了 6.8%。9–11 月占全年收入 36.8%，11 月一个月占 15.3%，典型的圣诞礼品批发生意。周六几乎不营业（两年 30 单）。
2. **留存**：2010 年 11 个新客群（3,288 人）第 1 个月留存 20.2%，之后稳定在 13–20% 不再衰减，第 12 个月反弹到 18.4%——礼品店为下一个圣诞季回来补货。
3. **RFM**：Champions 占客户 26%，贡献净收入 71.5%；前 10% 客户贡献 63.3%。"Cannot Lose Them" 102 人平均 13 单、£6.5k，但快一年没下单，是最该挽回的名单。
4. **复购**：71.4% 的客户下过 2 天以上的单，贡献 96.2% 的销售额；第二单中位间隔 63 天，60.9% 在 90 天内复购。
5. **退货**：取消额占销售额 3.65%；其中两笔批发大单（8 万件纸工艺品 £168k、7.4 万件储物罐 £77k）在录入后 12–16 分钟内取消，占取消额三分之一，去掉后是 2.4%。便宜陶瓷（杯、盘、碗）退货率高达 47–49%，大概率是运输破损。
6. **国家**：英国占 85.4%；海外客单价明显更高（欧洲 £797、其它 £1,336 vs 英国 £447）；法国 +58%、澳大利亚 +366%，爱尔兰 −27%。
7. **商品**：291 个 SKU（6%）贡献一半净收入；£1 以下商品占销量 41.5% 但只占销售额 11.5%；单张发票平均 25 行、283 件。

## 局限

数据从 2009-12 开始、没有更早历史，所以 2010 年初的"新客"里混着老客户回流（左截断）；13% 销售额是散客看不到客户号；没有成本、品类、营销数据；取消单和原单没有关联字段，用"同客户同商品最近一次销售"近似匹配。
